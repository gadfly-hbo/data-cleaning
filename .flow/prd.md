# PRD：本地数据不进 LLM 的自然语言 AI 清洗代码生成器

## 1. 目标与成功指标
- **运营人员零技术门槛**：输入自然语言即可生成并完成任何长尾复杂清洗。
- **数据不出本机（0 泄露风险）**：发送给大模型的 payload 仅包含：目标列名、字段类型、用户需求描述、以及当前列首行 1 个脱敏字样；全量业务数据 100% 由本地 `pybridge` 处理。
- **所见即所得**：生成清洗后 1 秒内给出前 10 行预览对比，用户确认后再全量应用。

## 2. 系统架构与数据流图

```
[前端: 运营输入大白话] 
        ↓ (仅带列名+用户提示词+1个首行样本)
[后端 studio-api / LLM 端点]
        ↓ (系统提示词严格限制只输出纯 Python 函数 clean_column(series))
[LLM (DeepSeek / OpenAI 兼容)]
        ↓ 返回纯函数代码
[本地沙箱 (pybridge)] -- 读取本地前 10 行数据试跑 --> 产出 Before/After 对比
        ↓
[前端: 弹出清洗前后对比浮层]
        ↓ 用户审核满意，点击「确认应用」
[本地 pybridge / OpenRefine] -- 毫秒级执行全量数据并生成新版本 (vN) --> 落盘
```

## 3. 详细接口设计

### 3.1 `POST /api/datasets/:id/ai/custom-cleaning/generate-preview`
- **Request Body**:
  ```json
  {
    "column": "该商品主要销售时间段",
    "prompt": "把时间段拆分成开始日期和结束日期，格式为 YYYY-MM-DD"
  }
  ```
- **安全阀控制**:
  - LLM 输入：严禁将整表上传，仅抽取当前列名、当前列 dtype、前 1~2 个样本值；
  - LLM 输出代码约束：生成 Python 函数 `transform(val: str) -> dict[str, Any]` 或 `transform(val: str) -> str`；
- **沙箱试跑**:
  - 本地 Python 子进程安全执行该函数处理当前数据集前 10 行；
  - 捕获异常：若语法错误或执行异常，自动携带报错反馈给模型自愈修正（最多 1 次重试）；
- **Response**:
  ```json
  {
    "code": "def transform(val):\n    ...",
    "action_name": "拆分销售起止日期",
    "preview": [
      { "row_index": 0, "original": "2026年3月1日-8月1日", "result": { "销售开始时间": "2026-03-01", "销售结束时间": "2026-08-01" } },
      { "row_index": 1, "original": "2026年3月1日-8月1日", "result": { "销售开始时间": "2026-03-01", "销售结束时间": "2026-08-01" } }
    ]
  }
  ```

### 3.2 `POST /api/datasets/:id/ai/custom-cleaning/apply`
- **Request Body**:
  ```json
  {
    "column": "该商品主要销售时间段",
    "code": "def transform(val):\n    ...",
    "action_name": "拆分销售起止日期"
  }
  ```
- **执行与落盘**:
  - 在本地 `pybridge` 中针对该文件进行全量转换；
  - 产出新文件，调用 OpenRefine 重建或更新项目，落盘为新版本（`vN`）；
  - 写入版本历史与审计日志；
  - 将该清洗算子保存到数据集的自定义规则库中。

## 4. UI 交互体验规范（契约对齐）
- 在「清洗」标签页的 ActionCards 顶部增加：
  - 【✨ AI 定制清洗】输入卡片：包含目标列下拉选择、自然语言需求输入框、以及「AI 分析并预览」按钮；
  - 支持快捷推荐（针对选中列自动给出 2~3 个可能的建议灵感）；
- 弹窗呈现「清洗前后效果对比」：
  - 表格列直观展现：【原始数据】 vs 【清洗后效果】；
  - 带有明显的「全量数据仅在本地计算，不会发送给云端」安全信任标签；
  - 底部操作按钮：【重试修改】、【确认应用并保存卡片】。
